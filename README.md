# Portfólio Unificado de Soluções para Corte de Custos
## Prefeitura Municipal de Sete Lagoas/MG

Consolidação de estudos de eficiência orçamentária em três secretarias: Educação, Saúde e Contratos Transversais.

### Arquivos

- **portafolio_unificado.html** — Versão completa com todos os estilos e interatividade
- **portafolio_unificado_artifact.html** — Variante sem DOCTYPE para publicação em plataformas web
- **portafolio_unificado_editavel.html** — Versão com editor inline (contenteditable + localStorage)

### Como Visualizar

Abra qualquer arquivo HTML em um navegador moderno. O documento é responsivo e funciona com tema claro/escuro automático.

### Geração Automatizada

Os arquivos são regenerados automaticamente:
```bash
python gerar_artifact.py      # Gera variante para Artifact
python gerar_editavel.py      # Gera versão editável
```

### Estrutura do Documento

**Parte I — Educação (5 frentes)**
- Contraturno e eficiência escolar
- Quadro administrativo por comparação entre pares

**Parte II — Saúde (10 frentes)**
- Compra agrupada de medicamentos
- Redesenho de atenção primária
- Contratos e hospitalização
- Reorganização de equipes

**Parte III — Contratos (6 casos)**
- Folha de pagamento
- Kits escolares
- Iluminação e sonorização
- Máquinas pesadas
- Sistemas de gestão
- Kits reagentes
